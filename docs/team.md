# 図面屋さん（ずめんや）

5体の Grok Bot ＋人（承認者）で、図面から仕上げ一覧を作るチーム。書き込みは zumennya-bot の API（Cloudflare Workers＋D1）だけ、Drive の原本は誰も変えない、承認は必ず人。

API の呼び出し方は [ボット向け API](bot-api.md)、記録が画面に出るまでの流れは [システムの流れ](system-flow.md)。

## ひろいだし（図面担当）

Drive の図面（PDF・スキャン）を読み、部屋・部位・仕上げ・品番の候補を根拠画像つきで登録する。読めない値は推測せず「要確認」にする。

- Skill：仕上げ一覧づくり：図面の読み取り（ひろいだし）

## かたろぐ（カタログ担当）

建材カタログを版ごとに登録し、廃番・後継品番を管理する。候補の品番を照合し、一致・不一致・照合保留・未登録・品番なしに分ける。名前が似ているだけでは確定しない。

- Skill：仕上げ一覧づくり：カタログ照合（かたろぐ）

## かくにん（独立レビュー）

候補を原本の図面と根拠画像だけで確かめ、重大／軽微の指摘を記録する。直った版を確かめて閉じる。

- Skill：仕上げ一覧づくり：独立レビュー（かくにん）

## おやかた（窓口・まとめ役）

人におすすめ付きで判断を聞き、返事どおりに判定を記録する。全件決まったら書き出しを指示する。

- Skill：仕上げ一覧づくり：まとめ役（おやかた）

## かきだし（書き出し）

全件決まったときだけ最終版を Google スプレッドシートと xlsx に書き出し、API と全件突き合わせて記録する。変更は版を上げる。

- Skill：仕上げ一覧づくり：書き出し（かきだし）

## Skill

5つとも、最初に初めて使う人向けのセットアップ（API・鍵・Drive のフォルダの用意）と API の呼び方を書き、そのあとに各自の手順をまとめています。

- [仕上げ一覧づくり：図面の読み取り（ひろいだし）](sand-workflow:skill-1791697065404)は、Drive の図面を読んで部屋・部位・仕上げ・品番の候補を根拠画像つきで登録するときと、指摘を受けて候補を直すときに使います。読み方の決まり、座標と画像の扱い、直し方が入っています。
- [仕上げ一覧づくり：カタログ照合（かたろぐ）](sand-workflow:skill-1791697107848)は、建材カタログを版ごとに登録して廃番を管理するときと、候補の品番を照合して一致・不一致・照合保留・未登録・品番なしに分けるときに使います。
- [仕上げ一覧づくり：独立レビュー（かくにん）](sand-workflow:skill-1791697147387)は、候補を原本の図面と根拠画像だけで確かめて重大か軽微の指摘を記録するときと、直った版を確かめて指摘を閉じるときに使います。
- [仕上げ一覧づくり：まとめ役（おやかた）](sand-workflow:skill-1791697018460)は、人におすすめ付きで判断を聞き、返事どおりに判定を記録して、全件決まったら書き出しを指示するときに使います。聞き方の基準もここに入っています。
- [仕上げ一覧づくり：書き出し（かきだし）](sand-workflow:skill-1791697193554)は、全件決まったあとに最終版を Google スプレッドシートと xlsx に書き出し、API と全件突き合わせて記録するときに使います。版の上げ方も入っています。

どれも鍵の値や案件の中身は入れていないので、そのまま人に共有できます。
